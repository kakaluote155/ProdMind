# ProdMind 1.0.0

**Software that knows why it broke — or why it got slow.**

ProdMind `v1.0.0` is the first stable release of the evidence-first, read-only Production Support Engineer.

Instead of starting from a generic alert or a pile of logs, ProdMind starts from the user's exact action, correlates it with production telemetry, builds normalized evidence, runs deterministic RCA, and produces separate customer-safe and engineer-facing explanations.

## What is included

- **User-action-first investigation** with browser trace-context correlation.
- **OpenTelemetry-native evidence collection** with Tempo, Loki and Prometheus connectors.
- **Deterministic RCA** for database uniqueness violations, downstream unavailability, database-pool exhaustion, slow database operations and slow downstream services.
- **Successful-but-slow analysis** without requiring an exception or HTTP 5xx.
- **Layered service topology** and an authenticated deterministic Evidence Graph.
- **Customer / engineer response isolation** so customer-facing APIs never receive raw operational evidence.
- **Project isolation** across telemetry, Incident Memory and Change Awareness.
- **Incident Memory** for compact historical operational knowledge without allowing history to replace current evidence.
- **Change Awareness** that treats deployments and configuration changes as context rather than automatic causation.
- **Optional grounded AI Investigator** with strict Evidence-ID citation checks, bounded sessions and no production mutation tools.
- **Embeddable integrations** for JavaScript, Spring Boot and Python/OpenTelemetry applications.
- **Production hardening** including project-bound engineer credentials, bounded connector transport, TLS/custom CA support, retention controls, CORS/trusted-host boundaries and a non-root production image.
- **Stable `/api/v1` contract**, installable release artifacts, checksums and automated release packaging.

## Why this is different

ProdMind follows one rule throughout the system:

> **Evidence First, AI Second.**

The AI layer is optional. It does not replace the authoritative root cause, invent telemetry or execute remediation. If current evidence is insufficient, ProdMind says so.

```text
User Action
    ↓
Trace + Logs + Metrics
    ↓
Normalized Evidence
    ↓
Deterministic RCA
    ↓
Root Cause
  ↙          ↘
Customer    Engineer Evidence Graph
answer             ↓ optional
              AI Investigator
```

## Try the demo

Linux / macOS:

```bash
git clone https://github.com/kakaluote155/ProdMind.git
cd ProdMind
bash scripts/demo-up.sh
```

Windows PowerShell:

```powershell
git clone https://github.com/kakaluote155/ProdMind.git
cd ProdMind
.\scripts\demo-up.ps1
```

Then open:

- Customer demo: `http://localhost:8090`
- Engineer Evidence Graph: `http://localhost:8088/engineer`
- API docs: `http://localhost:8088/docs`

The demo includes real PostgreSQL, OpenTelemetry, Tempo, Loki and Prometheus-backed scenarios.

## Safety boundary

ProdMind `v1.0.0` is deliberately **read-only**. It does not automatically run shell commands, restart services, modify databases, deploy code or mutate production resources.

The stable v1 product boundary is:

```text
Detect → Investigate → Explain → Recommend
```

Human-approved remediation remains future work.
